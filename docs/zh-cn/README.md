根据想要学习的内容和探索深度选择工作坊。**入门**将引导你了解 GitHub Copilot；**真实场景开发**则使用完整应用和团队待办列表，练习面向生产环境的工作流程。

## 入门

通过聚焦且循序渐进的体验，了解 GitHub Copilot 产品的主要功能，无需现有代码库。

### [GitHub Copilot 应用导览][first-steps-app]

从空文件夹开始构建太空问答游戏，将其发布到 GitHub，处理一个 issue，完成 Copilot 代码评审，安排自动化任务，并探索 Canvas 工作流。

### [GitHub Copilot CLI 入门][first-steps-cli]

在终端中构建同一个太空问答游戏、检查差异、在 worktree 中运行并行会话、先规划再编辑，还可以直接在 shell 中创建、合并和委派拉取请求。

### [Visual Studio Code 入门][first-steps-vscode]

在 VS Code 中构建太空问答游戏，在集成浏览器中测试，使用源代码管理发布，通过 GitHub 工具处理 issue 和拉取请求，并将工作移交给云会话。

## 真实场景开发

使用 Tailspin Toys 应用和待办列表，在真实的软件开发生命周期中练习使用 GitHub Copilot。选择工作环境，然后规划、构建、测试、评审并交付有意义的更改。

### [浏览真实场景开发工作坊][real-world-development]

可选择 GitHub Copilot CLI、GitHub Copilot 应用、GitHub Copilot 云代理或 Visual Studio Code。

> [!CAUTION]
> GitHub Copilot 具有概率性而非确定性，因此具体代码和修改的文件可能与示例不同。出现细微差异属于正常现象。
>
> 如果在讲师指导的研讨会中遇到无法正常运行的内容，请向导师求助。
